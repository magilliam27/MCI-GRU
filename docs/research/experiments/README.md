# Pre-registered Experiments

One committed `<id>.yaml` per experiment, written before its first run. The fields,
the template and the rules are in [`../EXPERIMENT_PROTOCOL.md`](../EXPERIMENT_PROTOCOL.md);
`mci_gru/preregistration.py` loads and enforces them (#372).

A file here is a declaration, not evidence. Its results are reported in
`../current/` once the experiment's ledger is complete.
