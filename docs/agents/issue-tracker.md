# Issue Tracker

MCI-GRU tracks implementation work in GitHub Issues for
`magilliam27/MCI-GRU`.

Agents should use GitHub issue numbers, titles, comments, and labels as the
durable work tracker when turning plans into implementation work. Local notes,
handoffs, and research reports can support an issue, but they do not replace
the issue tracker unless the user explicitly asks for a local-only workflow.

Before creating or closing issues, agents should confirm the current branch,
worktree state, and whether the user wants GitHub mutation.
